# Loghub HDFS_2k sample

`HDFS_2k.log_structured.csv` contains 2,000 lines of the HDFS_v1 log with event labels
assigned by hand by the Loghub authors. It is used to measure the grouping accuracy of the
template miner (in the tests and in `logfusion hdfs`).

- Source: https://github.com/logpai/loghub/blob/master/HDFS/HDFS_2k.log_structured.csv
- License: see [LICENSE](LICENSE), which must accompany every copy of the data.
- Original data: W. Xu, L. Huang, A. Fox, D. Patterson, M. I. Jordan. *Detecting Large-Scale
  System Problems by Mining Console Logs.* SOSP 2009.
- Collection: J. Zhu, S. He, P. He, J. Liu, M. R. Lyu. *Loghub: A Large Collection of System
  Log Datasets for AI-driven Log Analytics.* ISSRE 2023.
